jQuery Introduction

1. What is jQuery?

jQuery là một thư viện JavaScript nhỏ gọn, giúp viết ít code hơn nhưng thực hiện được nhiều công việc hơn.

jQuery giúp đơn giản hóa việc lập trình JavaScript trên website.

2. What You Should Already Know

  • CSS
  • JavaScript

3. jQuery Features

  • HTML/DOM manipulation
  • CSS manipulation
  • HTML event methods
  • Effects and animations
  • AJAX
  • Utilities

4. jQuery Plugins

Plugin là phần mở rộng giúp bổ sung các chức năng cho jQuery.

5. Why jQuery?

jQuery giúp đơn giản hóa nhiều thao tác JavaScript, tiết kiệm thời gian lập trình và hỗ trợ xử lý khác biệt giữa các trình duyệt.
